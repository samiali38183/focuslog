# FocusLog

A Pomodoro timer that also logs your focus sessions and shows a weekly summary. I made it to track my
own study time.

Live: [focuslog-ochre.vercel.app](https://focuslog-ochre.vercel.app)

## Features

- Focus/break timer with adjustable lengths and a circular progress ring
- Logs each finished session with a timestamp
- Weekly view of how many sessions you did each day
- Daily session goal
- Saves to localStorage, so your history stays after you close the tab

## Run it

It's one HTML file with no build step:

```bash
git clone https://github.com/samiali38183/focuslog.git
cd focuslog
```

Then open `index.html` in a browser.

Built with plain HTML, CSS and JavaScript. Hosted on Vercel.
